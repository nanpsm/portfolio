# Nan Phyu Sin Maung — Portfolio

**Live:** [nan-phyu-sin-maung.vercel.app](https://nan-phyu-sin-maung.vercel.app)

A museum-style personal portfolio built with Next.js 15, TypeScript, and fully custom inline styling. No UI library — every component is hand-crafted with the design language of a curated gallery.

---

## Rooms

| Room | Section |
|------|---------|
| I | Projects — carousel of shipped work |
| II | Skills — interactive book slider |
| III | Education — scroll timeline |
| IV | Credentials — framed exhibit wall |
| V | Contact — gift shop + guestbook |

---

## Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Inline styles + `useIsMobile` hook for responsive layout
- **Fonts:** Playfair Display, JetBrains Mono
- **Deployment:** Vercel

---

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
